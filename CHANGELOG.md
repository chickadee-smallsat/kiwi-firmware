# Changelog
All notable changes to this project will be documented in this file.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.0.3 [2026-11-13]
- Added support for data transmission over BLE.
- Added support for switching between WiFi and BLE.
- Added support for WiFi AP fallback mode if host SSID not found/could not connect.

## 0.0.2 [2026-06-17]
- Added firmware version display in the USB interface.
- Added support for baking Wi-Fi blobs into the firmware itself for easy UF2 export.
- Added documentation to build UF2 firmware blobs.

## 0.0.1 [2026-05-10]
- Initial public release.
